# PoA Model Card (v3.1)

## Model: Probability of Acceptance (PoA)

**Version:** PoA_v3.1  
**Vintage:** 2026-Q1

## Purpose

Predicts the probability that a borrower will accept a proposed settlement offer.

## Key Features

- Recent missed payments (negative driver)
- Long delinquency (negative driver)
- Low previous engagement (negative driver)
- High income stability (positive driver)
- Strong payment history (positive driver)
- Previous settlement acceptance (positive driver)

## Uncertainty

Always present predictions as probabilities with confidence intervals. Never state acceptance as a certainty.
